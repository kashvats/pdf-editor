# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Professionals, developers, legal teams, researchers, and students who need to edit, annotate, convert, redact, OCR, clean, and process sensitive PDF documents with guaranteed privacy.

## Product Purpose
A privacy-first, browser-native PDF workspace providing 50+ high-performance tools that execute entirely on the user's local machine with zero network transfers or cloud custody.

## Positioning
EditPDF eliminates document custody transfer by architecture: there are no backend upload endpoints, no processing queues, and no data retention. Everything runs locally in browser tabs via WebAssembly and Canvas.

## Operating Context
Confidential documents, contracts, bank statements, medical reports, and everyday documents where uploading files to third-party cloud servers poses legal, compliance, or privacy risks.

## Capabilities and Constraints
- 50+ client-side tools: In-place text editing, signing, true redaction, OCR with multi-language support, scan cleaning, batch processing, automated workflows, document comparison, digital signature inspection, data extraction, and offline AI summaries.
- Strict constraint: 100% on-device processing. No external backend server.

## Brand Commitments
- Name: EditPDF
- Visual World: Clean Swiss Editorial / Linear (Minimalist light theme, high-contrast monochrome with precision emerald accents, crisp typography, generous whitespace, structured grid rhythm).

## Evidence on Hand
Fully functional client-side React 18 application with Vite 5, pdf-lib, PDF.js, Tesseract.js, Canvas processing, and IndexedDB history.
